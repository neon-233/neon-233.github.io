Copy the matching POSCAR, POTCAR and converged CHGCAR from a uniform-mesh PBE SCF/DOS run. ICHARG=11 keeps the density fixed. KPOINTS is specifically for primitive vectors a1=(0,a/2,a/2), a2=(a/2,0,a/2), a3=(a/2,a/2,0). Path: L-G-X-U | K-G, disconnected U to K. Not a general path for conventional or distorted cells. Not an HSE workflow. Use a documented energy reference from SCF or the valence-band maximum.

Plot from the common parent directory of si-static and si-bands in a Jupyter environment with a compatible py4vasp version. Both calculations must have readable vaspout.h5 generated by an HDF5-enabled VASP build. This example assumes the bands CHGCAR came from si-static. If it came from si-dos, change the SCF reference path to si-dos as well. Keep structure, functional and POTCAR consistent.

import py4vasp
scf = py4vasp.Calculation.from_path("si-static")
ef = scf.dos.read()["fermi_energy"]
calc = py4vasp.Calculation.from_path("si-bands")
calc.band.plot(fermi_energy=ef)

The plot has already subtracted the explicitly supplied SCF Fermi energy. Do not subtract it a second time or use the line-path Fermi energy as a substitute. Without supported HDF5 outputs, record EF from the matching SCF OUTCAR and use another plotting tool with explicit energy alignment. No result data are bundled here.
